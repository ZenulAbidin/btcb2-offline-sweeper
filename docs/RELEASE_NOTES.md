Two guided Windows apps now handle the USB-based BTCB2 sweep workflow. Download the Offline ZIP for the disconnected signing computer and the Online ZIP for the connected computer. Extract the ZIP and open its EXE; Python is bundled.

- Public address export, online fork scan, offline review/signing, and explicitly confirmed online broadcast.
- File browsers and portable transfer packages for moving between two computers.
- Native standard Electrum wallet import, compatible BIP39 BIP44/BIP84 recovery phrases, and compressed WIF / legacy Core dumpwallet text.
- Builds include dependency hashes, executable self-tests, archive separation checks, licenses and SHA256SUMS.

Read `START-HERE.md` and `AUDIT.md` in either ZIP before beginning. This is a **prerelease** of the existing review-prototype signers. Internal security review and cross-review by separate AI agents were completed; no independent external security audit or full-node validation is claimed. Windows binaries are not Authenticode-signed. P2SH/BIP49, multisig, Taproot, Lightning and hardware-wallet signing are unsupported. Keep all wallet secrets on the offline computer.
