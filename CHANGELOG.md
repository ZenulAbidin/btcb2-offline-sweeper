# Changelog

## 0.1.0 — 2026-09-08

- Add separate interactive offline and online terminal applications with file selection and a four-step USB transfer workflow.
- Add native Electrum wallet loading, standard BIP39 BIP44/BIP84 account import, and compressed WIF / legacy Core key-dump import.
- Add public inventory, sweep request and signed package handling with offline review and explicit broadcast confirmation.
- Preserve the original SegWit and legacy signing tools and their upstream fixtures.
- Add Windows standalone EXEs, versioned ZIPs, SHA-256 checksums, dependency locking, CI and tag-triggered GitHub prereleases.
- Document wallet compatibility, beginner instructions, build procedures, signer limitations and the internal security review.
